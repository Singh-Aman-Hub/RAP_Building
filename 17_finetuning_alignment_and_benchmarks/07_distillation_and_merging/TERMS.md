## Knowledge distillation  `(concept)`
**1. Definition:** Training a student to match a teacher's output distribution: alpha*T^2*KL(softmax(t/T) || softmax(s/T)) + (1-alpha)*CE.
**2. In plain words:** The student copies the teacher's confidence, not just its final answers.
**3. Example to quote:** > "Teacher gpt2 and student distilgpt2 share one tokenizer, so token-level logit distillation works."
**Seen in:** `main.py`, `kd_loss`

## Soft targets and dark knowledge  `(concept)`
**1. Definition:** The teacher's full probability distribution, including the probabilities of wrong-but-plausible tokens.
**2. In plain words:** Which wrong answers are nearly right.
**3. Example to quote:** > "The teacher's wrong-but-close probabilities (dark knowledge) tell the student how classes relate, which a hard label hides."
**Seen in:** `main.py`, section 2

## Temperature (T)  `(concept)`
**1. Definition:** Divides logits before softmax; T>1 flattens the distribution.
**2. In plain words:** Turn the contrast down so small probabilities show.
**3. Example to quote:** > "Dividing the logits by T=2 flattens the teacher's distribution, so its small probabilities become visible to the student."
```python
F.softmax(z / T, -1)
```
**Seen in:** `main.py`, `entropy`

## T squared factor  `(concept)`
**1. Definition:** Soft-target gradients scale like 1/T^2, so the KL term is multiplied by T^2.
**2. In plain words:** Keep the balance with the hard loss constant.
**3. Example to quote:** > "Multiplying the soft loss by T squared keeps its gradient size comparable when T changes."
```python
alpha * (T ** 2) * kl
```
**Seen in:** `main.py`, `kd_loss`

## KL(teacher || student)  `(concept)`
**1. Definition:** Expected log-ratio of teacher to student probabilities under the teacher; zero when equal.
**2. In plain words:** How far the student is from the teacher.
**3. Example to quote:** > "I minimise KL(teacher || student): the student must put mass wherever the teacher does."
```python
(t * (torch.log(t + 1e-12) - s)).sum(-1)
```
**Seen in:** `main.py`, `kd_loss`

## Sequence-level distillation  `(concept)`
**1. Definition:** Train the student on text generated by the teacher, instead of matching logits.
**2. In plain words:** Imitate the teacher's writing.
**3. Example to quote:** > "Works across tokenizers and with API-only teachers."
**Seen in:** `WALKTHROUGH.md` theory

## Task vector  `(concept)`
**1. Definition:** tau = theta_finetuned - theta_base, the change a fine-tune made.
**2. In plain words:** The edit, separated from the base.
**3. Example to quote:** > "A task vector is fine-tuned weights minus base weights; merging means adding scaled task vectors to the base."
```python
tau1 = theta_ft1 - theta_base
```
**Seen in:** `main.py`, section 5

## Linear averaging (model soup)  `(concept)`
**1. Definition:** Merged weights are the mean of the models' weights.
**2. In plain words:** Average the recipes.
**3. Example to quote:** > "Interference shrinks each task's effect."
```python
(tau1 + tau2) / 2
```
**Seen in:** `main.py`, section 5

## Task arithmetic  `(concept)`
**1. Definition:** theta_base + lambda * sum of task vectors.
**2. In plain words:** Add the skills.
**3. Example to quote:** > "Also adds interference when vectors conflict."
```python
tau1 + tau2
```
**Seen in:** `main.py`, section 5

## SLERP  `(concept)`
**1. Definition:** Spherical linear interpolation: (sin((1-t)w) a + sin(t w) b)/sin(w), with w the angle between the vectors.
**2. In plain words:** Walk along the arc, not the chord.
**3. Example to quote:** > "Keeps the norm: for two random unit vectors the SLERP norm is 1.0, the linear mean 0.70 (solutions/s07_slerp_check.py)."
```python
def slerp(a, b, t): ...
```
**Seen in:** `main.py`, `slerp`

## TIES merging  `(concept)`
**1. Definition:** Trim small entries of each task vector, elect a sign per coordinate by total mass, average only the agreeing entries.
**2. In plain words:** Keep the strong, agreeing edits and drop the rest.
**3. Example to quote:** > "density=0.5 keeps the top half by magnitude."
```python
def ties(taus, density=0.5): ...
```
**Seen in:** `main.py`, `ties`

## Interference between tasks  `(concept)`
**1. Definition:** Two fine-tunes edit the same weights in conflicting directions.
**2. In plain words:** Two people editing one document.
**3. Example to quote:** > "The toy makes 150 of 1000 coordinates exactly opposite."
```python
tau2[:150] = -tau1[:150] + ...
```
**Seen in:** `main.py`, section 5

## Cosine similarity  `(concept)`
**1. Definition:** Dot product of normalised vectors: 1 same direction, 0 orthogonal.
**2. In plain words:** Do two vectors point the same way?
**3. Example to quote:** > "Used to ask how close a merged delta is to each task vector."
```python
F.cosine_similarity(a, b, dim=0)
```
**Seen in:** `main.py`, section 5

## add_weighted_adapter  `(library)`
**1. Definition:** peft method to build a new adapter from existing ones with weights and a combination_type such as 'linear' or 'ties'.
**2. In plain words:** Mix two adapters into a third.
**3. Example to quote:** > "Linear requires equal ranks."
```python
pm.add_weighted_adapter(['a','b'], [0.5,0.5], adapter_name='lin', combination_type='linear')
```
**Seen in:** `main.py`, section 6

## disable_adapter  `(library)`
**1. Definition:** Context manager that runs the base model with adapters turned off.
**2. In plain words:** The 'before' model, for free.
**3. Example to quote:** > "with pm.disable_adapter() I get the plain base model back to measure the before-numbers."
```python
with pm.disable_adapter(): ...
```
**Seen in:** `main.py`, section 6

## Multi-adapter serving  `(concept)`
**1. Definition:** One frozen base in memory with several small adapters selected per request.
**2. In plain words:** One engine, many hats.
**3. Example to quote:** > "One frozen base model in memory plus many small adapters, switched per request."
```python
pm.set_adapter('a')
```
**Seen in:** `main.py`, section 6
