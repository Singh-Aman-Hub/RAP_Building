Rule: each day = 1 new problem (dry run on paper → brute → optimised → asserts) + 1 *rebuild from memory* of a problem from 3 days ago.
Problems marked (code) are already implemented in this module — read **after** attempting yourself. Names are standard LeetCode titles.
