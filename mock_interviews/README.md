# Mock Interviews

Practise *out loud*, with a timer, closed notes. Use after each gate in [../ROADMAP.md](../ROADMAP.md#7-readiness-checks).

| File | Use |
|------|-----|
| [question_bank.md](question_bank.md) | Cross-module "bridge" questions with model answers (connected understanding) |
| [live_coding_drills.md](live_coding_drills.md) | Timed coding tasks: Python, DSA, agent loop, API |
| [debugging_drills.md](debugging_drills.md) | Cold debugging practice using the `broken_*` files already in the pack |
| [scorecard.md](scorecard.md) | Self-scoring sheet; track weak areas |

Protocol: 45 min = 5 min explain a past project/capstone, 20 min live coding, 10 min debugging drill, 10 min concept questions. Record yourself once; listen for filler and unexplained jargon.
Each module README also has its own interview Q&A.
